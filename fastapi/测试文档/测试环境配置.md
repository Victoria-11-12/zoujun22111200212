# 测试环境配置

## 创建测试配置文件


### 步骤 1：复制模板文件

```bash
cd fastapi
cp .env.test.example .env.test
```

### 步骤 2：修改配置

打开 `.env.test` 文件，根据你的本地环境修改以下配置：

| 配置项 | 需要修改 | 说明 |
|--------|----------|------|
| `DB_PORT` | `3306` | 本地数据库默认端口 |
| `DB_PASS` | 你的密码 | 本地数据库 root 密码 |
| `DB_PASS_READONLY` | 你的密码 | 如未创建只读用户，改为 root 密码 |
| `DB_PASS_ANALYST` | 你的密码 | 如未创建分析师用户，改为 root 密码 |
| `API_KEY` | 你的密钥 | DeepSeek API 密钥 |
| `EVAL_API_KEY` | 你的密钥 | DeepSeek API 密钥（可与上面相同） |

## 配置项说明

### 数据库配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `DB_HOST` | `127.0.0.1` | 数据库主机地址 |
| `DB_PORT` | `3306` | 数据库端口 |
| `DB_USER` | `root` | 管理员用户名 |
| `DB_PASS` | - | 管理员密码 |
| `DB_NAME` | `movie_db` | 数据库名称 |
| `DB_USER_READONLY` | `root` | 只读用户名 |
| `DB_PASS_READONLY` | - | 只读用户密码 |
| `DB_USER_ANALYST` | `root` | 分析师用户名 |
| `DB_PASS_ANALYST` | - | 分析师密码 |

### LLM API 配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `API_KEY` | - | DeepSeek API 密钥 |
| `MODEL_NAME` | `deepseek-v4-flash` | 对话模型名称 |
| `API_BASE` | `https://api.deepseek.com/v1` | API 基础地址 |
| `EVAL_API_KEY` | - | 评估模型 API 密钥 |
| `EVAL_MODEL_NAME` | `deepseek-v4-flash` | 评估模型名称 |

## 运行测试

配置完成后，在 `fastapi` 目录下运行：

```bash
# 运行所有测试
pytest

# 运行单元测试
pytest tests/unit -m unit

# 运行集成测试
pytest tests/integration -m integration

# 运行端到端测试
pytest tests/e2e -m e2e
```

## 测试依赖

运行测试前请确保已安装测试依赖：

```bash
pip install pytest pytest-asyncio pytest-html pytest-cov
```
